# Security

The model is not the security, permission, execution or verification boundary. Shell/sudo/raw-command paths are denied by Gen-2 control surfaces. Gen-1 ToolRegistry remains authoritative with exact allow sets. Models cannot self-approve, downgrade risk, alter policy, self-verify, expose credentials or self-install improvements. Self-improvement requires tests, review and human approval. Audit records are hash chained and tamper detection is tested.
