# Multimodal

SPARKLE validates bounded text/image/audio/document/video/screen/camera transport independently from semantic understanding. The NVIDIA Omni route provides certified semantic image/perception inference where a bounded image source is supplied; text remains routed to Lightning. Audio semantic transport is separate from VoiceChat realtime speech-to-speech. The hosted VoiceChat WebSocket and speech-to-speech path are live-verified, but production voice remains fail-closed because the hosted deployment has not honored the required PersonalAgent function delegation. Physical camera/sensor availability is never inferred from model capability. Artifact and file provenance may be stored without claiming hardware observation.

## Personal Core image input

The authenticated Personal Core now exposes a bounded in-memory image bridge for PNG, JPEG, and WebP. The PWA accepts at most 4 MB of raw image bytes, base64 encodes them for the local API request, and never supplies an arbitrary filesystem path. The server independently validates base64, content magic/MIME agreement, size, digest, and modality through `MultimodalGateway`; the original image bytes are passed transiently to the configured `multimodal` route and are not written to the Gen-2 store. Only bounded image metadata, model/provider provenance, and the resulting text interpretation may enter the conversation/goal path.

Audio uploads validate through the same bytes-only boundary but production voice still fails closed while authorization-safe hosted function delegation remains unverified. The master-finalization run independently reverified real Omni image semantics with fallback disabled. A full Personal Core image → Omni → subsequent PersonalAgent planning probe was cancelled after exceeding the bounded acceptance window, so the UI bridge is software-accepted while the underlying Omni semantic provider remains live-accepted; that timed-out composite probe is not counted as live end-to-end acceptance.
