# Experiments and Engineering

Experiment records include hypothesis, method, configuration, dataset, code version, model, project/research linkage, observations, results, metrics and conclusion. Research-to-experiment orchestration performs research retrieval, candidate comparison, experiment design, approval, independently verified execution, analysis and documentation.

The software-engineering loop is bounded to inspect -> implement -> verify/test -> diagnose -> fix -> retest -> review -> package/report through Gen-1 controlled workspace operations. The dedicated execution worker remains externally blocked when disabled.
